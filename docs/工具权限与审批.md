# 工具权限与审批

在 MiniBot 应用主目录下的全局 `config/default.yaml` 中设置 `tool_permissions`。省略该配置时使用 `mode: "off"`，沿用现有行为。更新文件后重启 REPL 或 WebUI 服务。

## 请求人工审批

将模式设为 `manual`，按工具名称分配 `allow`、`deny` 或 `ask`。未单独列出的工具采用 `default` 规则。

```yaml
tool_permissions:
  mode: manual
  default: ask
  rules:
    read_file: allow
    askuserquestion: allow
    write_file: ask
    edit_file: ask
    bash: deny
    Task: allow
  timeout: 120
```

REPL 和 WebUI 会在执行前询问。查看工具名称、发起请求的 Agent 和参数，再批准或拒绝本次调用。每次新调用均需单独决定。被拒绝的调用在任何前置工具钩子或工具代码运行之前停止。批准后仍会执行原有的前置钩子和工具检查。

分发规则适用于主 Agent、内置子 Agent、团队成员及 WebUI 中已挂载的 Bot 所发出的模型请求。子 Agent 原有的工具允许列表仍然适用。文件工具接受工作区相对路径或工作区内的绝对路径。MiniBot 在审批和执行前各解析并校验一次目标路径。

WebUI 和流式 SDK 的审批绑定到当前活跃运行。超时、取消、流结束或重启后，待审批请求失效。超时以秒为单位，也计入活跃的运行预算。没有审批者的交互，例如无处理器的非流式 SDK 调用或没有活跃负责人的团队成员，会拒绝需要人工批准的调用。无人值守运行需要使用的工具应设为允许。

## 启用 AI 审查

设置 `mode: auto_review` 并提供以工作区为基准的相对路径。命中 `ask` 规则时，可使用运行配置的模型审核这些路径内的内置写入或编辑操作。模式对照路径解析后的值匹配，例如 `notes/report.md`。含隐藏路径组件的操作不进入 AI 审查。

```yaml
tool_permissions:
  mode: auto_review
  default: ask
  rules:
    read_file: allow
    askuserquestion: allow
    write_file: ask
    edit_file: ask
    bash: deny
    Task: allow
  auto_review_paths:
    - "notes/**"
  timeout: 120
```

审核模型收到独立提示词，无可用工具。输入包含用户请求和拟执行的文件工具参数，限制为 4,000 字符。审查使用当前运行的模型服务商，计入模型和 token 预算。审查结果不明确、无效、不可用或超出适用范围时，交给人工处理。AI 审查无法批准 Bash、MCP 或自定义工具调用。显式的 `deny` 规则优先于任何审查。

## 在 SDK 中处理审批

通过 `Config` 传入 `ToolPermissionsConfig`。对于需要人工确认的非流式调用，向 `Minibot` 传入异步 `tool_approval_handler`。处理器收到含准确调用预览的 `ToolApprovalRequest`，返回 `True` 表示仅批准本次调用。异步流也可处理 `tool_approval_request` 事件，随后向同一 Bot 提交决定。

```python
async for event in bot.stream("更新 notes/report.md"):
    if event["type"] == "tool_approval_request":
        approved = await your_confirmation_ui(event)
        bot.submit_tool_approval(event["approval_id"], approved)
```

WebUI API 客户端可以用 `POST /api/bots/{bot_id}/sessions/{session_id}/tool-approvals/{approval_id}` 处理活跃请求，请求体包含布尔字段 `approved`。已过期、已使用或不匹配的 ID 返回 HTTP 409。审批决定独立于持久化的用户回答。

启用执行追踪时，JSONL 会记录审批 ID、工具名、决定与来源。审批预览和审核提示词不写入追踪文件。此策略控制模型请求的工具分发。可信 Python 插件、Hooks 和直接调用的 Python 函数保留宿主机访问权限。
