# 运行模型文件任务评估

在仓库检出目录中，为兼容 OpenAI API 的服务商设置 `OPENAI_API_KEY`。使用其他服务商时，将 `OPENAI_BASE_URL` 设为其 API 基础 URL，再用其模型 ID 运行评估。

```sh
uv run python -m minibot.eval_model --model MODEL_ID --repetitions 3 > model-eval.json
```

脚本向服务商发送合成的文件任务提示词。每次试验在独立的临时工作区运行 MiniBot SDK，使用内置的读取、写入和编辑工具。使用 `--task create-note` 或 `--task update-inventory` 选择任务。可重复传入 `--model` 在同一端点比较多个模型。

JSON 报告包含每次试验的结果，以及按任务和模型统计的通过率。运行完成且产生的文件集合和内容符合预期，即算通过。报告记录模型请求、工具调用尝试以及服务商报告的输入和输出 token。只要汇总的某个请求缺少计数，对应总数就是 `null`。传输重试计入同一次 MiniBot 请求。每次试验限有效运行 60 秒，其他限制列在报告中。

退出码 `0` 表示全部通过，`1` 表示至少一项失败，`2` 表示参数校验失败或缺少 API Key。需要无需服务商凭证的确定性测试时，运行[离线任务回归检查](执行追踪.md#run-the-task-regression-checks)。
