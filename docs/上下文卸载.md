# 上下文卸载

MiniBot 把大型文本工具结果保存为本地产物。工具结果包含不透明的产物 ID，空间允许时附带简短预览。Agent 可搜索产物或读取指定范围，无需把完整输出发给模型。Bash、文件读取、MCP 工具和自定义文本工具采用相同规则。

## 配置

以下是应用主目录中 `config/default.yaml` 的默认设置。

```yaml
llm:
  max_tool_output_chars: 16000
context_offloading:
  enabled: true
  threshold_chars: null
  max_artifact_bytes: 8388608
```

- `enabled` 默认为 `true`。设为 `false` 可恢复原有输出限制并移除检索工具。
- `threshold_chars` 是触发卸载的字符数，默认采用 `llm.max_tool_output_chars`。显式配置可以降低该阈值。
- `max_artifact_bytes` 是单个产物 UTF-8 内容的字节上限，默认 8 MiB，支持 1 字节至 64 MiB。超出采集上限或存储失败时，工具会报错，底层命令或工具可能已经执行。

Python SDK 可通过 `Config(context_offloading=ContextOffloadingConfig(...))` 采用相同设置，两个类均从 `minibot.config` 导入。

## 检索工具

| 工具 | 结果 |
| --- | --- |
| `read_artifact(artifact_id, offset, limit)` | 精确的文本切片。默认偏移量为 0。`limit` 的默认值和最大值均取 4,096 与 `llm.max_tool_output_chars` 中较小者。结果短于请求长度表示已读到结尾。 |
| `search_artifact(artifact_id, query)` | 由 `[match_offset, snippet_offset, snippet]` 组成的 JSON 数组。采用区分大小写的字面匹配，查询最多 256 个字符，在相同输出限制内返回最多 20 条结果。 |

偏移量从零开始，按 Unicode 字符计数。工具接受当前会话中的产物 ID，遵循同样的[权限](工具权限与审批.md)和[运行预算](运行预算.md)。工具允许列表含有对应工具时，内置 `Task` 子 Agent 也能检索产物。团队 Agent 采用各自的会话范围。

## 存储与限制

- 产物保存在应用主目录的 `artifacts/` 中。重开会话时沿用同一应用主目录、工作区、会话目录和会话 ID。压缩或重开后，模型收到最近最多八个产物引用。已知 ID 仍可读取旧产物。
- 产物会保留在磁盘上，直到被删除。MiniBot 不会自动清理，也没有总磁盘配额。若需防止工作区工具或容器直接读取记录，请在工作区之外使用私有应用主目录。本地 Bash 仍以 MiniBot 的操作系统权限运行。
- 保存的是工具的文本结果。卸载 Bash 输出时先保存 stdout，再保存 stderr，替换无效的 UTF-8 字节。非零退出保留原有错误前缀和退出码。大型 UTF-8 文件读取保留原换行符，显式行数限制仍生效。
- 启用[执行追踪](执行追踪.md)时，追踪记录产物创建、搜索和读取，包含 ID、大小及调用 ID 等元数据。查询和产物文本不写入追踪。
