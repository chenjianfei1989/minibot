# 第 12 讲 长期记忆数据库与检索

区分会话记录、长期记忆文件与结构化记忆数据库。

## 记忆和会话记录能回答不同的问题

「我刚才问的那句话是什么？」适合从当前会话历史找。「这个项目一直沿用什么术语？」则可能需要跨会话读取长期记忆。MiniBot 的记忆层既有长期、每日文本文件，也有结构化的数据库节点。先从 `MemoryManager` 观察这两套入口，然后在运行时确认某次工具或 WebUI 请求走的是哪一套。

## 读一条结构化记忆

假设建一个命名空间，用一个节点保存术语，再更新节点内容。用 `db_models.py` 核对命名空间、节点、版本、触发词和搜索文档的表模型。沿 `repository.py` 找创建、更新和索引维护，接着从搜索方法进入排序逻辑。读搜索结果时同时留意命名空间、过滤条件及匹配信息，这些条件决定「存在」和「可在本次被查到」是否一致。

使用 SQLite 时，到 `db.py` 查应用主目录和记忆目录怎样组成数据库路径。切到 PostgreSQL 或 MySQL 时，再查连接地址规范化和后端初始化。阅读实验可以用临时 SQLite 会话观察版本和搜索，不需要远程数据库。

**思考与答案**　看到新节点能读取但搜不到，第一步查什么？先核对搜索所选命名空间和过滤条件，再检查对应的搜索文档是否随变更更新。

## 五张记忆表的用途

| 表名 | 用途 |
| --- | --- |
| `memory_namespaces` | 结构化记忆命名空间，保存空间名称和说明，用于隔离不同范围的记忆。 |
| `memory_nodes` | 结构化记忆节点，保存目录层级、记忆正文和当前状态。 |
| `memory_node_versions` | 记忆节点的历史版本，保存每次变更时的快照和变更详情。 |
| `memory_triggers` | 记忆触发词，记录关键词与记忆节点的关联，供检索匹配使用。 |
| `memory_search_documents` | 结构化记忆检索文档，汇总标题、正文等内容用于搜索匹配。 |

新建 MySQL 表时，数据库会保存这些表注释。已经创建的表可以在选中 MiniBot 使用的数据库后执行以下语句补上注释。

```sql
ALTER TABLE memory_namespaces COMMENT = '结构化记忆命名空间，保存空间名称和说明，用于隔离不同范围的记忆。';
ALTER TABLE memory_nodes COMMENT = '结构化记忆节点，保存目录层级、记忆正文和当前状态。';
ALTER TABLE memory_node_versions COMMENT = '记忆节点的历史版本，保存每次变更时的快照和变更详情。';
ALTER TABLE memory_triggers COMMENT = '记忆触发词，记录关键词与记忆节点的关联，供检索匹配使用。';
ALTER TABLE memory_search_documents COMMENT = '结构化记忆检索文档，汇总标题、正文等内容用于搜索匹配。';
```

## 配置核对

逐项读 MemoryConfig 中的启用、目录、数据库后端、连接参数和读取范围。对照 SQLite 默认路径及两个服务端数据库后端的初始化方式。

### 使用 MySQL

先在 MySQL 中创建一个数据库并授予 MiniBot 使用的账号建表、创建索引和读写权限。通过 WebUI 的「配置 → 记忆数据库」选择 MySQL 并填写连接地址，或手动编辑 `~/.minibot/config/default.yaml`。

```yaml
memory:
  backend: mysql
  database_url: ${MEMORY_DATABASE_URL}
```

在 `~/.minibot/.env` 设置连接地址，将示例中的账号、密码和库名换成实际值。

```dotenv
MEMORY_DATABASE_URL=mysql+pymysql://minibot_user:YOUR_PASSWORD@127.0.0.1:3306/minibot_memory
```

也支持 `mysql://`，MiniBot 会选择 PyMySQL 驱动。若密码中有 `@` 等 URL 保留字符，需要先做百分号编码。保存配置后，重启 WebUI 或重新创建 SDK 实例，让现有会话使用新配置。首次访问结构化记忆时，MiniBot 会在目标库中创建五张记忆表。原有 SQLite 或 PostgreSQL 数据不会自动迁移，会话记录和长期、每日文本记忆仍保存在文件中。

## 使用与验证

在临时目录用 SQLite 仓库创建和更新记忆节点，读它的历史版本，再从 WebUI 的记忆页面找对应入口。

在仓库根目录运行本讲的定向测试。测试可在未配置真实模型凭证的环境中执行。

```powershell
uv run --with pytest --with pytest-asyncio python -m pytest -q tests/test_memory_repository.py::test_create_update_move_and_delete_node_records_versions
```
