# 第 15 讲 文件检查点与产物

分辨文件回滚、工具输出保存和运行记录三种用途。

## 源码导读

先读 GitFileCheckpoints 的捕获与回滚判断，找出文件字节、权限和冲突检查的位置。再读 ArtifactStore 的保存、按 ID 读取与范围检索，区分产物记录与运行日志中的引用。

[file_checkpoints.py](../../src/minibot/file_checkpoints.py) · [core/artifacts.py](../../src/minibot/core/artifacts.py) · [tools/builtin/artifact.py](../../src/minibot/tools/builtin/artifact.py) · [ui/cmd_checkpoint.py](../../src/minibot/ui/cmd_checkpoint.py)

## 配置核对

file_checkpoints 控制文件快照，依赖受支持的 Git 工作树和工作区模式。产物的内容大小与卸载阈值由 context_offloading 控制。

[相关配置与使用指南](../文件检查点.md)

## 使用与验证

在临时 Git 工作树用 /checkpoint list、diff 和 rollback 查看写入产生的快照。没有相应运行环境时，先读禁用行为的测试。

在仓库根目录运行本讲的定向测试。测试可在未配置真实模型凭证的环境中执行。

```powershell
uv run --with pytest --with pytest-asyncio python -m pytest -q tests/test_file_checkpoints.py::test_disabled_checkpoints_preserve_normal_non_git_writes
```

## 阅读验收

能说明回滚之前为什么要比对文件状态，以及为什么读取产物不会撤销文件修改。
