# 第 11 讲 上下文窗口压缩与卸载

理解历史变长时，到底有哪些数据进入模型。

## 源码导读

先读 prepare_model_request() 的窗口检查、工具文本截断和旧轮次筛选。再定位 Agent 的上下文压缩分支，最后看大文本结果如何成为本地产物，并由 read_artifact 或 search_artifact 按需读回。

[core/model_context.py](../../src/minibot/core/model_context.py) · [agent.py](../../src/minibot/agent.py) · [core/artifacts.py](../../src/minibot/core/artifacts.py) · [tools/builtin/artifact.py](../../src/minibot/tools/builtin/artifact.py)

## 配置核对

对照 llm.max_context_tokens、max_tokens、max_tool_output_chars 和压缩阈值，再检查 context_offloading 的 enabled、threshold_chars、max_artifact_bytes。

[相关配置与使用指南](../上下文卸载.md)

## 使用与验证

用假模型让输入使用量超过测试阈值，观察压缩消息及之后的请求。另从卸载指南对照产物引用和原文本的存储位置。

在仓库根目录运行本讲的定向测试。测试可在未配置真实模型凭证的环境中执行。

```powershell
uv run --with pytest --with pytest-asyncio python -m pytest -q tests/test_context_compaction.py::test_agent_run_loop_triggers_compaction
```

## 阅读验收

能对比请求裁剪、压缩摘要和产物卸载分别改动的数据，以及会话原记录是否还在。
