# 第 05 讲 参数解析分发与回填

跟踪一次模型发出的工具调用直到下一次模型请求。

## 源码导读

在 _dispatch_tool_batch() 追踪 call_id、name 和 arguments。parse_tool_arguments() 尝试解析并处理可恢复的格式问题。沿工具注册表查找、参数校验与执行路径，定位结果如何按 tool_call_id 写入模型消息。

[agent.py](../../src/minibot/agent.py) · [core/tool_args.py](../../src/minibot/core/tool_args.py) · [tools/registry.py](../../src/minibot/tools/registry.py) · [tools/function.py](../../src/minibot/tools/function.py)

## 配置核对

本讲同时追踪工具是否已注册与工具参数是否有效。权限、Hooks 和预算的拒绝结果在下一讲及第 13 讲展开。

## 使用与验证

给同一工具准备正常对象和无效 JSON，对照返回值及诊断。记录无效参数时工具函数是否被执行。

在仓库根目录运行本讲的定向测试。测试可在未配置真实模型凭证的环境中执行。

```powershell
uv run --with pytest --with pytest-asyncio python -m pytest -q tests/test_tool_args.py
```

## 阅读验收

能从一条 role=tool 的消息反查调用 ID、工具名和原始参数，并解释坏参数怎样继续反馈给模型。
